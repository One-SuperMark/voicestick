## 本版更新

- 新增「检查更新…」：可从状态栏菜单主动检查 VoiceStick 新版本，同时保留「当前版本」显示。
- 接入应用内更新：客户端使用 One-SuperMark fork 自己的更新渠道，后续正式版本可通过应用内提示下载并安装，不再需要每次到 GitHub 手动寻找安装包。
- 加强更新安全校验：更新清单与安装包使用本 fork 的独立签名，客户端在安装前验证签名；正式安装包继续使用 Developer ID 签名和 Apple 公证。
- 完善 ARM64 发布流程：正式发版同时提供 DMG、签名更新清单和 SHA-256 校验文件，并核对版本号、更新地址及签名公钥的一致性。
- 更新窗口显示实际变更说明：应用内更新提示与 GitHub 发版公告使用同一份中文说明。

## 安装与升级说明

- 本版适用于 Apple Silicon Mac，要求 macOS 12 或更新版本，不提供 Intel 安装包。
- 0.3.5 及更早的已发布版本没有启用本 fork 的更新器，首次升级到 0.3.6 仍需手动安装：退出旧版，打开 DMG，将 VoiceStick.app 拖入「应用程序」替换旧版，再启动并确认当前版本为 0.3.6。
- 安装 0.3.6 后，后续版本可通过「检查更新…」获取；检查更新不等于不经确认自动安装。
- 本版只更新 macOS 客户端及发布链路，没有修改 StickS3 固件，不需要重新烧录设备。
