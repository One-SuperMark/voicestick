## 本版更新

- 修复设备断开后，录音浮窗和状态栏仍停留在 `Processing` 的问题。断开时及时收起对应设备的浮窗，全部设备断开时状态栏显示 `Disconnected`，不再把搜索、准备或未知状态误判为正在处理。
- 明确区分蓝牙已连接与音频传输已准备就绪：链路仍在准备时显示 `Preparing…`，收到设备就绪通知或有效音频帧后再更新就绪状态。
- 修复断开、重新连接或开始下一轮录音后，旧的语音识别、翻译及浮窗回调可能覆盖新状态的问题；清理已失效的前键长按判定，防止延迟触发录音。
- 改善多设备状态隔离：一个设备断开、完成识别或进入就绪状态时，不清除另一台设备仍在进行的录音或处理状态。
- 保留已完成的输入及可恢复的上一次输入，并补充状态切换、回调取消和重连场景的自动化回归测试。
- 已经松键、正在等待音频结束的主输入，仍按原策略保留缓冲语音的最终识别；设备离线显示与这类有效识别结果独立处理。

## 安装与升级说明

- 本版适用于 Apple Silicon Mac，要求 macOS 12 或更新版本，不提供 Intel 安装包。
- 已安装带在线更新功能的正式版用户，可通过「检查更新…」获取 0.3.8；安装仍由用户确认。原有配对、语音服务配置和辅助功能授权不主动重置。
- 本版只更新 macOS 客户端及测试，没有修改 StickS3 固件，无需重新烧录设备。
- 本次重点是断开与重连时的客户端状态及回调管理，不改变语音识别服务、网络连接方式或识别超时参数。
