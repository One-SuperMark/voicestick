## 本版更新

- 精简状态栏菜单：移除「打开辅助功能设置」和「当前版本」两项，保留「设置…」「检查更新…」及原有授权引导。
- 本地开发版本支持四段显示：例如 `0.3.7.1（开发版）`，可在检查更新窗口和设置窗口标题中辨认当前构建轮次。
- 开发构建自动编号：使用 `--development` 成功打包后递增第四段，失败不占用编号，切换正式版本基线后从 `.1` 开始。
- 正式更新仍使用三段版本：开发编号独立保存，不改变 Apple 版本字段、远程正式版本或应用内更新的版本比较。
- 增加版本显示、开发编号与异常状态的回归测试，并补充本机开发安装及云端正式发布的流程说明。

## 安装与升级说明

- 本版适用于 Apple Silicon Mac，要求 macOS 12 或更新版本，不提供 Intel 安装包。
- 正式发布后，已安装 0.3.6 的用户可通过「检查更新…」获取 0.3.7；更新安装仍由用户确认。
- 本地开发包的四段号仅用于识别开发构建，不属于公开正式版本，不上传正式更新源。GitHub Actions 测试包与 Developer ID 签名、公证的正式包仍分别提供和验证。
- 本版只更新 macOS 客户端、测试和构建流程，没有修改 StickS3 固件，不需要重新烧录设备。
